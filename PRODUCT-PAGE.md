# Vocavista product page

Product/share URL: https://prdesalvo.github.io/vocavista-privacy/vocavista/

Static HTML/CSS in `vocavista/`, published through this GitHub Pages repository, built the same way as Flip's page (`flip-privacy/flip/`). Preserve every root privacy/support/config file. No build step, analytics, external fonts or JavaScript dependency.

Copy follows the draft App Store listing (`language-learning-ios/docs/app-store-listing.md`). Screenshots are from the iPhone 18 Pro Max simulator (iOS 27.0) on November 20, 2026, using the shipped Animals starter pack in an empty test store, resized from 1320 × 2868 to 660 × 1434. The icon is `AppIcon.icon` rendered with Icon Composer's `ictool` at 512 px. Store links use app ID 6826015529; they open the App Store listing once Vocavista is released.
